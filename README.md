# inlook-nya-outlook

Statiskt Outlook-tillägg (nya Outlook) som skapar uppgifter och
anteckningar från mejl via Microsoft Graph (OneDrive). Kalender och To Do utelämnas: de kräver administratörsgodkännande. Ingen backend. Innehåller inga
användardata; allt lagras i användarens eget OneDrive/To Do.

Se INSTALLERA.md. Konfiguration (offentlig): js/config.js. MSAL.js (MIT) ligger
i vendor/.
